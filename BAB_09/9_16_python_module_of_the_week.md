# Exercise 9-16 — Python Module of the Week

Modul pilihan: `statistics` (dokumentasi resmi:
https://docs.python.org/3/library/statistics.html).

Modul ini menyediakan fungsi statistik seperti mean (rata-rata), median,
dan mode (modus). Contoh:

```python
import statistics
scores = [80, 85, 90, 90, 95]
print(statistics.mean(scores))
print(statistics.median(scores))
print(statistics.mode(scores))
```

Relevansi: modul ini dapat dipakai untuk menganalisis nilai mahasiswa,
data produksi, atau pengukuran proses.
