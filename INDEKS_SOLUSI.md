# Indeks Exercise dan Catatan Solusi

Setiap nomor memiliki file `.py` pada folder bab yang sesuai.

| Bab | Cakupan | Nomor |
|---|---|---|
| 2 | Variabel, string, angka, komentar, Zen of Python | 2-1 sampai 2-12 |
| 3 | List, perubahan elemen, urutan, indeks | 3-1 sampai 3-11 |
| 4 | for, range, list comprehension, slicing, tuple, PEP 8 | 4-1 sampai 4-15 |
| 5 | Conditional tests, if/elif/else, membership | 5-1 sampai 5-13 |
| 6 | Dictionary, looping, nesting | 6-1 sampai 6-12 |
| 7 | input(), while, sentinel, break, list/dictionary dengan loop | 7-1 sampai 7-10 |
| 8 | Fungsi, argumen, return, list, arbitrary arguments, modules | 8-1 sampai 8-17 |

## Batasan dan penyesuaian

- Latihan 2-5/2-6 memakai kutipan Albert Einstein sebagai contoh. Pilih kutipan lain bila dosen meminta tokoh pilihan sendiri.
- Data orang, nama, kota, makanan, dan favorit pada latihan Bab 3/6 adalah data ilustratif. Silakan ganti dengan data yang kamu pilih.
- Latihan 4-14 dan 5-12 merupakan peninjauan panduan gaya; 4-15 adalah review program, sehingga hasilnya bergantung pada tiga file yang diperiksa. Alat `4_15_code_review.py` memeriksa hal dasar, bukan keseluruhan spesifikasi PEP 8.
- Latihan 5-13 bersifat personal; daftar yang diberikan hanya contoh ide.
- Latihan 6-12 merupakan satu contoh perluasan dari dictionary tempat favorit.
- Latihan 7-7 dibuat aman dihentikan melalui `quit` selain `Ctrl+C`.
- Latihan 8-15 dan 8-16 memakai file modul pendukung. Simpan struktur foldernya seperti semula agar import berhasil.
